How does auto-detect work? What about mixed-language recordings?

Language. The recording is cut at pauses into parts of up to about 30 seconds. On Auto-detect, the model decides the language of each part separately.

Speakers. The speaker model turns short stretches of voice into “voice prints” and groups similar ones. It counts the groups, so a quiet or very short speaker can be missed, and one voice in two moods can be split in two. Setting the number makes it exact.

Example: a Cantonese speaker, an interpreter into Mandarin, and a Mandarin speaker. Leave Language on Auto-detect and set Number of speakers to 3. Choosing Cantonese would force the Mandarin parts to be written as Cantonese too. For mixed Cantonese/Mandarin, the Qwen3-ASR model (Models tab) is clearly better than Whisper. A part where both languages are spoken gets one language, so check those lines.

Settings

Hugging Face token

Needed once for gated models (pyannote diarization). Create a free token at huggingface.co/settings/tokens, and accept the terms of pyannote/speaker-diarization-community-1 (and, only if you use the older 3.1 model, speaker-diarization-3.1 + segmentation-3.0). The token is stored locally and only used to download models.

Compute device

Changing device takes effect the next time models are loaded.

Job history

Finished jobs (transcript + original audio) are kept on disk so playback and editing survive restarts. Oldest jobs beyond this limit are deleted automatically (3–20, default 5).

Access & security

When on, devices other than this computer must enter the API key (browser) or send it as a Bearer token (API). This machine (localhost) is never asked.

Server port

Saving restarts the web server on the new port (models stay loaded — no re-download). You'll be redirected; other devices must reconnect to the new port. If a login is active it will be required again on the new port.
